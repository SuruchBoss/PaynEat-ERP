# ADR-0004: ต้นทุนราย lot ตามจริง การตัดใช้แบบ FEFO และการปันต้นทุนให้ผลิตภัณฑ์ร่วม

- **สถานะ:** ยอมรับแล้ว
- **วันที่:** 2026-09-25
- **English:** [0004-lot-costing-and-cost-allocation.md](0004-lot-costing-and-cost-allocation.md)

## บริบท

ไก่ทั้งตัวน้ำหนัก 1.8 กก. จะกลายเป็นน่อง สะโพก ปีก อก โครงไก่สำหรับต้มน้ำสต๊อก และของเสียส่วนหนึ่ง ต้นทุนการซื้อต้อง
ไปลงอยู่ที่ผลผลิตเหล่านั้น และผลผลิตแต่ละชนิดมีมูลค่าต่อกิโลกรัมต่างกันมาก นอกจากนี้วิธีคิดต้นทุนยังต้องสอดคล้องกับ
วิธีหยิบสต๊อก ไม่เช่นนั้นต้นทุนที่รายงานกับความเป็นจริงทางกายภาพจะค่อยๆ ห่างออกจากกัน

## การตัดสินใจ

1. **ทุก lot มีต้นทุนต่อหน่วยตามจริงติดตัว** ใบรับสินค้ากำหนดต้นทุนนี้จากราคาในใบสั่งซื้อหลังหัก VAT ที่ขอคืนได้ ส่วน
   lot ผลผลิตจากการผลิตได้ต้นทุนจากการปันต้นทุนตามข้อด้านล่าง
2. **การตัดใช้ใช้ต้นทุนของ lot ที่ถูกตัด** การเบิกจ่าย การนำวัตถุดิบเข้าการผลิต การโอน และการใช้ที่สาขา จะเลือก lot แบบ
   **FEFO** (หมดอายุก่อนออกก่อน) และรายการเคลื่อนไหวแต่ละรายการจะมีต้นทุนของ lot ที่ถูกเลือกติดไปด้วย ต้นทุนและการไหล
   ทางกายภาพจึงเป็นไปตามกฎเดียวกัน
3. **ต้นทุนการผลิตปันตามสัดส่วนที่กำหนดในสูตรการผลิต** ผลผลิตแต่ละตัวของสูตรการผลิตมีสัดส่วนปันต้นทุน ต้นทุนรวมของ
   lot วัตถุดิบนำเข้าที่ถูกใช้จะถูกแบ่งให้ผลผลิตแต่ละตัวตามสัดส่วนเหล่านั้น แล้วหารด้วยจำนวนจริงของผลผลิตแต่ละตัว
   ได้เป็นต้นทุนต่อหน่วยของ lot ผลผลิต **สัดส่วนตั้งต้นคือสัดส่วนตามน้ำหนักผลผลิตที่คาดไว้** และโรงงานสามารถกำหนดค่า
   ทับได้ (เช่น ให้อกได้สัดส่วนสูงกว่าโครงไก่) ของเสียไม่มีต้นทุน ต้นทุนของส่วนนั้นถูกผลผลิตรับไว้แทน ซึ่งทำให้อัตราผลได้
   ที่ต่ำมองเห็นได้ในรูปของต้นทุนต่อหน่วยที่สูงขึ้น
4. **การโอนส่งต้นทุนต่อไปโดยไม่เปลี่ยนแปลง** ใน v1 การย้าย lot จากโรงงานไปสาขาไม่เปลี่ยนต้นทุนต่อหน่วยของ lot นั้น
5. **จนกว่าจะมีการจับคู่สามทาง (three-way matching) ต้นทุนรับเข้าคือราคาในใบสั่งซื้อ** หากใบแจ้งหนี้ของซัพพลายเออร์
   ต่างออกไปในภายหลัง v1 จะไม่ปรับมูลค่า lot ที่ถูกใช้ไปแล้ว ข้อจำกัดนี้บันทึกไว้ที่นี่และใน issue เรื่อง three-way
   matching

## ผลที่ตามมา

- ต้นทุนอธิบายได้ทีละบรรทัด: การใช้ที่สาขารายการใดก็ตามสามารถตามรอยไปยัง lot ไปยังใบสั่งผลิต ไปจนถึงใบรับสินค้าจาก
  ซัพพลายเออร์และราคาของใบนั้นได้
- ปัญหาอัตราผลได้ปรากฏออกมาในรูปของต้นทุน: ใบสั่งผลิตที่ได้อัตราผลได้ 60 % แทนที่จะเป็น 70 % จะได้ชิ้นส่วนที่แพงขึ้น
  อย่างเห็นได้ชัด
- ใน v1 ค่าแรงและค่าโสหุ้ยไม่ถูกรวมเข้าในต้นทุนการผลิต ต้นทุนผลิตภัณฑ์คือต้นทุนวัตถุดิบ คาดว่าต้นทุนแรงงานจะมาจาก
  Cwork ในภายหลัง (ADR-0001)

## ทางเลือกที่พิจารณา

- **ต้นทุนถัวเฉลี่ยถ่วงน้ำหนักแบบเคลื่อนที่ (moving weighted average)** ง่ายกว่า แต่ทิ้งข้อมูลราย lot ที่บัญชีเคลื่อนไหว
  มีอยู่แล้ว และขัดแย้งกับการหยิบแบบ FEFO ในเรื่องที่ว่าสต๊อกส่วนไหนถูกใช้ไป
- **ต้นทุนมาตรฐานพร้อมการวิเคราะห์ส่วนต่าง (standard cost with variances)** พบบ่อยในผู้ผลิตรายใหญ่และเป็นสิ่งที่ดีที่จะ
  เพิ่มในภายหลัง แต่ต้องมีรอบการคิดต้นทุนและรายงานส่วนต่างที่จะกินพื้นที่ส่วนใหญ่ของรุ่นแรก
- **ปันตามน้ำหนักเท่านั้น** ปฏิเสธในฐานะทางเลือกเดียว: วิธีนี้ทำให้อกกับโครงไก่มีราคาต่อกิโลกรัมเท่ากัน ซึ่งไม่มีโรงงาน
  ไหนยอมรับ แต่ยังคงเป็นค่าตั้งต้น
