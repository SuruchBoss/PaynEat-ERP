# ADR-0007: การรับสินค้า การตรวจรับ และการโอน

- **สถานะ:** ยอมรับแล้ว
- **วันที่:** 2026-09-25
- **English:** [0007-receiving-inspection-and-transfers.md](0007-receiving-inspection-and-transfers.md)

## บริบท

เนื้อสัตว์แช่เย็นมาถึงโรงงานจากซัพพลายเออร์ และออกจากโรงงานไปยังสาขา ที่จุดส่งมอบทั้งสองจุด จำนวนอาจขาด สินค้าอาจ
เสียหาย อุณหภูมิอาจอยู่นอกช่วงที่กำหนด หรือวันหมดอายุอาจใกล้เกินไป หากส่วนต่างถูกกลืนหายไปอย่างเงียบๆ สต๊อกจะผิด
และไม่มีใครต้องรับผิดชอบ

## การตัดสินใจ

1. **ใช้โมเดลการตรวจรับเดียว** ในทุกการรับ: ใบรับสินค้าจากซัพพลายเออร์และการรับโอนที่สาขาบันทึกข้อมูลชุดเดียวกันในแต่ละ
   บรรทัด — จำนวนที่นับได้ (และจำนวนหน่วยที่สองสำหรับรายการน้ำหนักแปรผัน, ADR-0005) อุณหภูมิขณะรับ สภาพสินค้า และ
   วันหมดอายุ
2. **ค่าที่ยอมรับได้กำหนดแยกต่อรายการสินค้า ไม่ hard-code ไว้ในโค้ดเด็ดขาด:** ส่วนต่างของจำนวนสูงสุดเป็นเปอร์เซ็นต์ และ
   อุณหภูมิขณะรับสูงสุด สิ่งใดที่อยู่นอกค่าที่ยอมรับได้ต้องมีเหตุผลและการอนุมัติจากบทบาทอื่นที่ไม่ใช่บทบาทของผู้รับ
   (ADR-0008)
3. **การโอนต้องผ่านสถานะระหว่างขนส่ง** การส่งของ (dispatch) ที่ต้นทางจะยืนยัน lot และจำนวนที่หยิบ แล้วย้ายไปยังสถานที่
   เก็บสต๊อกระหว่างขนส่ง การรับที่ปลายทางจะย้ายสิ่งที่มาถึงจริงเข้าสู่ปลายทาง
4. **ส่วนต่างต้องเป็นเอกสาร ไม่ใช่การหายไป** จำนวนที่ขาดหรือเสียหายตอนรับโอนจะถูกส่งคืนต้นทางหรือตัดจำหน่าย พร้อม
   เหตุผล ไม่มีทางค้างอยู่ในระหว่างขนส่ง และไม่มีทางหายไปเฉยๆ สินค้าจากซัพพลายเออร์ที่ถูกปฏิเสธจะออกเป็นใบส่งคืนสินค้า
5. **ทั้งสองฝั่งต้องรับผิดชอบ** สถานที่ต้นทางที่ส่งยืนยันสิ่งที่ออกไป สถานที่ปลายทางที่รับยืนยันสิ่งที่มาถึง และส่วนต่าง
   ระหว่างสองค่านี้มองเห็นได้บนใบโอน

## ผลที่ตามมา

- อุณหภูมิของห่วงโซ่ความเย็นถูกบันทึกเป็นข้อมูล ณ จุดที่สำคัญ ไม่ใช่เป็นแบบฟอร์มกระดาษ
- สต๊อกระหว่างขนส่งมองเห็นได้ตลอดเวลา ของบนรถบรรทุกจึงไม่เคย "หายไปไหนไม่รู้"
- การรับสินค้าใช้เวลานานกว่าการพิมพ์จำนวนอยู่บ้าง นั่นคือราคาของสต๊อกที่เชื่อถือได้

## ทางเลือกที่พิจารณา

- **ย้ายสต๊อกจากต้นทางไปปลายทางโดยตรงตอนส่งของ** ปฏิเสธ: ปลายทางจะแสดงสต๊อกที่ตัวเองยังไม่ได้รับ
- **แยกโมเดลการตรวจรับสำหรับซัพพลายเออร์และสำหรับการโอน** ปฏิเสธ: ทั้งสองบันทึกข้อเท็จจริงเดียวกัน และสองโมเดลจะ
  ค่อยๆ เบี่ยงออกจากกัน
